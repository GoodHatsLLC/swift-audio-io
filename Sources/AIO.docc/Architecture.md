# Architecture

This section contains documents related to the architecture and design of the project.

## Overview

The project is composed of two main parts:

*   **AIOEngine:** A Swift 6 concurrency-safe audio recording and playback engine.
*   **Recorder‽:** A demo application that showcases the capabilities of the `AIOEngine`.

The architecture is designed to be modular and extensible, with a clear separation between the core audio engine and the application logic.
