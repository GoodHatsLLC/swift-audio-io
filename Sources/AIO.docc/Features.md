# Features

AIO's public features are grouped around the ``AIOEngine`` umbrella product:

- Recording with typed configuration, multi-channel format validation, rotation, and
  writer-drain protection.
- File and segment playback with segment-relative scrubbing.
- Audio-session environment monitoring for route changes, interruptions, input devices,
  sample rates, and channel counts.
- Real-time visualization through ``AudioVisualizationEngine`` and token-scoped buffer
  receiver subscriptions.
- Offline waveform analysis through ``OfflineLODExtractor`` and the multi-band LOD types.
